# Xcode

Entwicklungsumgebung für die [[iPhone-App]] auf dem Mac. Das fertige Projekt liegt unter `app-ios/HydroDesk.xcodeproj` (Beschreibung in `project.yml` für XcodeGen). Xcode liefert das iOS-SDK und die Signierung – auch dann, wenn man aus VS Code über das Terminal baut.

Die App wurde mit Xcode für das iPhone gebaut und installiert. Mit der kostenlosen Apple-ID (Personal Team) läuft sie nur **7 Tage** und muss danach neu aufgespielt werden.

Siehe auch: [[Design-Spezifikation]], [[VS Code und PlatformIO]].
